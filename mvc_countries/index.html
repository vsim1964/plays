Что происходит при поиске?

Событие input вызывает обработчик контроллера. Контроллер передаёт поисковый запрос модели, получает от неё отфильтрованный массив посредством функции getVisibleCountries() и передаёт его функции представления renderCountries().

Повторного запроса к JSON при поиске, фильтрации и сортировке не происходит. Модель использует уже загруженный массив.
