# MVC без классов: личный состав отделения

Учебное приложение на HTML, CSS и JavaScript. Данные хранятся в `fighters.json` (статический «сервер»); `fetch()` получает их по HTTP. ООП, классов и библиотек нет.

## Кто за что отвечает

- `index.html` — разметка и подключение `main.js` через `type="module"`.
- `main.js` — единственная точка запуска.
- `controller.js` — реагирует на действия пользователя и связывает Model с View.
- `model.js` — хранит массив бойцов, фильтрует и сортирует его (не знает о DOM).
- `data.js` — обращается к `fighters.json` с помощью `fetch()`.
- `view.js` — читает поля формы и меняет DOM (не загружает данные).
- `fighters.json` — исходные данные в формате JSON.
- `style.css` — оформление.

## Цепочка при загрузке

`index.html → main.js → startController() → loadFighters() → fetchFighters() → fighters.json`.

После ответа: `model.js → controller.js → view.js → DOM`.

При вводе текста в поиск: `input → controller.js → model.js (filter) → controller.js → view.js (render)`. Новый HTTP-запрос при этом **не выполняется**.

Откройте инструменты разработчика → Console: каждый слой пишет свой этап.

## Запуск

`fetch()` и ES-модули нужно запускать через HTTP, не через `file://`.

Из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/mvc_fighters/`.

Также можно использовать VS Code Live Server или GitHub Pages. В корне папки есть `index.html`, поэтому адрес папки открывает приложение автоматически.

## Проверка MVC

1. Обновите страницу — JSON загружается один раз.
2. Введите «Москва» — отобразится соответствующий боец без нового запроса.
3. Выберите звание и сортировку — контроллер передаст настройки модели.
4. Нажмите «Загрузить JSON заново» — выполнится новый `fetch()`.
