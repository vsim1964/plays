Личный состав отделения

Один набор данных — три обязанности: модель хранит и отбирает, представление рисует, контроллер связывает действия.

fighters.jsonИсточник данных

↔

index.html подключает main.js; main.js запускает контроллер. Кнопки и поля ввода передают события контроллеру, который обращается к модели и обновляет представление.

Что происходит при поиске?

Событие input → функция контроллера → функция модели getVisibleFighters() → функция представления renderFighters() → новая таблица HTML. Повторного запроса к JSON при фильтрации нет: модель использует уже загруженный массив.
