// DATA: единственное место, где приложение обращается к «серверу».
// Этот код представляет собой модуль получения данных (Data Layer).
// Его задача — запросить JSON-файл, проверить, что данные получены
// и имеют правильную структуру, а затем передать массив бойцов
// другим частям программы.
// fighters.json — статический файл, имитирующий ответ API.

### 1. Объявление асинхронной функции

```js
export async function fetchFighters() {}
```

function — объявляет функцию с именем fetchFighters.

async — указывает, что функция асинхронная. Она может ожидать завершения операций, например получения файла с сервера. Вызов такой функции всегда возвращает Promise — объект, представляющий результат, который будет получен позднее.

export — делает функцию доступной другим JavaScript-модулям. Например, другой файл сможет импортировать её:

### 2. Запрос JSON-файла

```js
const response = await fetch("./fighters.json", {
  cache: "no-store",
});
```

### 3. Проверка ответа сервера

fetch() — встроенная функция JavaScript, которая отправляет HTTP-запрос. В нашем случае она запрашивает файл fighters.json.

"./fighters.json" — относительный URL. Путь определяется относительно адреса загруженного модуля или страницы в зависимости от контекста; в обычном браузерном модуле вызов fetch() разрешает такой URL относительно адреса документа.

cache: "no-store" — указание браузеру не использовать HTTP-кеш для этого запроса и не сохранять полученный ответ в нём.

await — приостанавливает выполнение данной асинхронной функции до получения ответа на запрос. Остальная работа браузера при этом не останавливается.

const response — создаёт переменную response, в которой сохраняется объект ответа сервера.

Обратите внимание: на этом этапе мы ещё не получили массив бойцов. Мы получили HTTP-ответ, содержащий статус, заголовки и тело ответа.

```js
if (!response.ok) {
  throw new Error(`HTTP ${response.status}: не удалось получить fighters.json`);
}
```

После получения ответа программа проверяет, успешно ли выполнен запрос.
response.ok — логическое свойство объекта ответа. Оно равно true, если HTTP-статус находится в диапазоне 200–299.
! — оператор логического отрицания. Он меняет true на false и наоборот.

Следовательно:
if (!response.ok)
означает: «Если сервер вернул ответ с неуспешным HTTP-статусом, выполнить следующий блок».

throw new Error(...) — создаёт исключение и прерывает нормальное выполнение функции. При этом возвращаемый функцией Promise переходит в состояние отклонения (rejected).

Например, если файл отсутствует, сервер может ответить:
HTTP 404: не удалось получить fighters.json

Конструкция:
`HTTP ${response.status}: ...`
называется шаблонной строкой. Она записывается в обратных кавычках и позволяет вставлять значения переменных или выражений через ${...}.

### 4. Преобразование ответа в JavaScript-объект

`const data = await response.json();`

Это один из главных этапов.
Файл fighters.json содержит текст в формате JSON.
Метод response.json() читает тело ответа и разбирает JSON, превращая его в соответствующее значение JavaScript — в данном примере объект с полем squad.

Метод тоже возвращает Promise, поэтому используется await.

После выполнения инструкции:
`const data = await response.json();`

переменная data содержит объект:
{
squad: [
{ name: "Алексей Петров", rank: "сержант" },
{ name: "Иван Соколов", rank: "рядовой" }
]
}

Теперь к его свойствам можно обращаться обычными средствами JavaScript:
data.squad
data.squad[0]
data.squad[0].name

### 5. Проверка структуры данных

```js
if (!Array.isArray(data.squad)) {
  throw new Error("Неверный формат JSON: ожидается массив squad");
}
```

Функция ожидает, что полученный объект содержит свойство squad, значением которого является массив.
Array.isArray() — встроенный метод JavaScript, проверяющий, является ли переданное значение массивом.

Например:
Array.isArray([1, 2, 3]); // true
Array.isArray("Привет"); // false
Array.isArray({a: 1}); // false

Следовательно, проверка:
!Array.isArray(data.squad)
означает: «Если data.squad не является массивом, сообщить об ошибке».

Проверяется именно тип контейнера, а не содержание каждого объекта. Например, функция примет даже пустой массив [] или массив чисел [1, 2]. Проверки имени, звания и остальных полей бойца здесь нет.

### 6. Вывод полученных данных в консоль

`console.log("[DATA] JSON получен:", data);`

Это диагностическая инструкция.
В консоли разработчика появится сообщение о том, что JSON успешно прочитан и прошёл проверку на наличие массива squad.

Например:
[DATA] JSON получен: { squad: Array(2) }

При раскрытии объекта в консоли можно посмотреть содержимое массива.
Префикс [DATA] написан самим программистом, чтобы отличать сообщения модуля данных от сообщений других частей приложения.

console.log() ничего не передаёт другим модулям и не создаёт таблицу на странице. Он лишь выводит информацию для разработчика.

### 7. Возвращение результата

`return data.squad;`

Это заключительная инструкция.
Мы получили объект data, проверили его и теперь возвращаем только массив бойцов, содержащийся в свойстве squad.
То есть функция возвращает не весь объект:
{
squad: [
{ name: "Алексей Петров" },
{ name: "Иван Соколов" }
]
}

а только:
[
{ name: "Алексей Петров" },
{ name: "Иван Соколов" }
]

Поскольку функция объявлена с async, этот массив становится результатом успешно завершившегося Promise.
Другой модуль может получить его следующим образом:
`const fighters = await fetchFighters();`

`console.log(fighters);`

Здесь fighters уже содержит массив, с которым можно работать: перебирать его, сортировать, фильтровать и передавать функции, отвечающей за отображение таблицы.
