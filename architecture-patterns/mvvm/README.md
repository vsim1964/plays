# MVVM — Model, View, ViewModel

**Основной вопрос:** как обновлять интерфейс вслед за изменениями наблюдаемого состояния?

В MVVM **ViewModel** хранит состояние, пригодное для интерфейса, и уведомляет подписчиков об изменениях. В данном примере реактивная связь создана вручную через `subscribe()` и `notify()`; никакой фреймворк не требуется.

## Распределение файлов

- `model.js` — `createModel()` возвращает исходный массив.
- `viewmodel.js` — `SquadViewModel`: `state={items, selected}`; методы `subscribe()`, `notify()`, `select()`, `changeRank()`.
- `view.js` — DOM-функции отображения и подключения обработчиков.
- `main.js` — связывает ViewModel и View: подписывается через `vm.subscribe(...)` и отправляет команды через `vm.changeRank(...)`.

## Маршрут изменения звания

```text
View.onSave(...)
      ↓
ViewModel.changeRank(index, rank)
      ↓
ViewModel изменяет state.items и вызывает notify()
      ↓
Подписчик из main.js получает state
      ↓
View.render(state.items) → таблица
```

Обратите внимание, что `ViewModel` не содержит `document.querySelector()`, а `View` не управляет массивом самостоятельно. В `main.js` находится связующий код, который вручную имитирует механизм data binding.

## Небольшой эксперимент

Закомментируйте `this.notify()` в `changeRank()`. Данные изменятся в состоянии ViewModel, но подписчик не узнает об этом и таблица останется прежней.

## Чем отличается

По сравнению с **MVP** функция обновления вызывается не напрямую из метода презентера, а после **уведомления о состоянии**. Реальные Vue/Angular применяют более развитые реактивные механизмы; этот пример иллюстрирует принцип, но не является реализацией этих фреймворков.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/mvvm/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
