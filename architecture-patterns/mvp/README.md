# MVP — Model, View, Presenter

**Основной вопрос:** как сделать представление пассивным и поручить всю координацию отдельному объекту?

В MVP **Presenter** получает сообщения от View, обращается к Model и явно говорит View, что показать. Представление здесь занимается DOM и событиями, но не принимает решений о данных.

## Распределение файлов

- `model.js` — `SquadModel` хранит бойцов, предоставляет `getAll()` и `setRank()`.
- `view.js` — `createView()` содержит только средства отрисовки и уведомления о действиях.
- `presenter.js` — `SquadPresenter` получает обработчики `onSave()`, вызывает модель, а потом `show()`.
- `main.js` — создаёт Model, View и Presenter.

## Маршрут изменения звания

```text
View: пользователь нажал кнопку
       ↓
Presenter.changeRank(index, rank)
       ↓
Model.setRank(index, rank)
       ↓
Presenter.show() → View.render(...)
       ↓
Обновлённая таблица
```

В `presenter.js` найдите метод `show()`: Presenter получает `model.getAll()` и передаёт их представлению. Сам View не читает Model напрямую.

## Небольшой эксперимент

В методе `show()` уберите вызов `this.view.render(...)`. Модель изменится, но Presenter перестанет отдавать представлению команду на перерисовку.

## Чем отличается

MVP особенно подчёркивает **пассивность View** и централизованную логику его обновления. В отличие от **MVVM**, здесь нет механизма подписки View на изменение состояния. В отличие от **Flux**, нет общего хранилища с действиями и reducer.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/mvp/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
