# Component-Based Architecture — компоненты интерфейса

**Основной вопрос:** как собирать страницу из самостоятельных повторно используемых деталей?

Компонент получает входные данные (**props**) и создаёт часть интерфейса. В нашей версии компоненты — обычные JavaScript-функции, а не React или Vue.

## Распределение файлов

- `model.js` — массив `squad` и функция `changeRank()`, создающая обновлённый массив.
- `components.js` — два компонента: `FighterRow({fighter})` создаёт DOM-строку, `SquadTable({fighters,target})` создаёт все строки.
- `main.js` — корневой код приложения: слушает события, обновляет модель, вызывает `SquadTable(...)`.
- `index.html` — контейнер для таблицы и органы управления.

## Как строится страница

```text
main.render()
       ↓
SquadTable({fighters, target})
       ↓
для каждого бойца → FighterRow({fighter})
       ↓
<tr> с пятью <td>
       ↓
tbody.replaceChildren(...строки)
```

Здесь разделение проходит **по частям интерфейса**, а не по классической тройке Model–View–Controller. Компонент строки можно использовать в другой таблице, поскольку он принимает объект бойца и возвращает готовый DOM-узел.

## Небольшой эксперимент

В `components.js` измените порядок имён полей в массиве внутри `FighterRow`. Порядок данных в каждой строке изменится, а `SquadTable` и модель менять не придётся. Затем верните первоначальный порядок.

## Чем отличается

Компонентная архитектура **совместима** с MVC, MVVM и Flux. Она отвечает на вопрос «из каких частей состоит интерфейс?», а Flux — «как меняется общее состояние?». В React компоненты обычно декларативны; у нас они возвращают DOM-элементы напрямую.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/components/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
