# Flux — однонаправленный поток данных

**Основной вопрос:** как сделать изменения состояния предсказуемыми и прослеживаемыми?

В этом учебном варианте Flux есть **Action** (описание действия), **Reducer** (функция вычисления следующего состояния) и **Store** (хранилище, которое уведомляет подписчиков). Это близкая к Redux организация, без установки Redux.

## Распределение файлов

- `model.js` — `initialState` и чистая функция `reducer(state, action)`. Изменённый боец создаётся копированием объекта; новое состояние — копированием массива.
- `store.js` — `createStore()`: хранит `state`, предоставляет `dispatch()`, `subscribe()`, `getState()`.
- `view.js` — DOM-представление.
- `main.js` — подписывает View на Store и посылает действие `{type:"CHANGE_RANK",index,rank}`.

## Маршрут изменения звания

```text
View → dispatch({type:"CHANGE_RANK", index, rank})
            ↓
Store вызывает reducer(state, action)
            ↓
Reducer возвращает НОВОЕ состояние
            ↓
Store уведомляет подписчиков
            ↓
View.render(state.squad)
```

В отличие от прямого вызова `model.changeRank()`, на вход Store отправляется **объект с описанием команды**. Единственное место, где решается, каким станет состояние, — reducer.

## Небольшой эксперимент

Измените строку `action.type === "CHANGE_RANK"` на другое имя действия. Store получит команду, но reducer вернёт старое состояние — таблица не изменится. Верните исходное имя.

## Чем отличается

От **MVVM** — централизованным описанием изменений через действия и reducer. От **Event-Driven** — тем, что события здесь предназначены для контролируемого изменения состояния с определённым направлением потока, а не для произвольного оповещения множества обработчиков.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/flux/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
