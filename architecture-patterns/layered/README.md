# Layered Architecture — многослойная архитектура

**Основной вопрос:** как отделить пользовательский интерфейс, правила обработки и доступ к данным?

Многослойная архитектура направляет вызовы через несколько специализированных уровней. В этом примере слои намеренно просты, чтобы можно было увидеть весь маршрут одного действия.

## Распределение файлов

- `view.js` — слой представления: создаёт строки и принимает действия пользователя.
- `controller.js` — принимает событие, обращается к сервису и обновляет View.
- `service.js` — `SquadService`: прикладная логика, проверка непустого звания, вызов репозитория.
- `repository.js` — `SquadRepository`: хранит массив в памяти и предоставляет `getAll()` / `saveRank()`.
- `main.js` — собирает зависимости.
- `data.js` — начальные данные.

## Маршрут изменения звания

```text
View
  ↓
Controller.change (обработчик onSave)
  ↓
SquadService.changeRank(index, rank)
  ↓
SquadRepository.saveRank(index, rank)
  ↓
Controller.show() → View.render(...)
```

Контроллер не записывает данные напрямую. Сервис не создаёт HTML-ячейки. Репозиторий не знает, какой кнопкой пользователь вызвал изменение.

## Небольшой эксперимент

Откройте `service.js` и добавьте более строгое правило проверки звания. Например, запретите пустую строку или отдельное значение. Это изменение не должно требовать переписывания `repository.js` или `view.js`.

## Чем отличается

В **MVC** основное различие — между моделью, представлением и контроллером. Здесь акцент сделан на **последовательности слоёв**, в частности на отдельном сервисе и репозитории. В **Clean Architecture** дополнительно важна направленность зависимостей: центральные правила должны оставаться независимыми от внешних механизмов.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/layered/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
