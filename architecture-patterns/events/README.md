# Event-Driven Architecture — взаимодействие через события

**Основной вопрос:** как сообщать о произошедшем действии, не вызывая напрямую все заинтересованные модули?

В событийной архитектуре компоненты публикуют сообщения, а подписчики на них реагируют. Наш посредник — простейшая синхронная **шина событий (Event Bus)**.

## Распределение файлов

- `bus.js` — `createBus()`: методы `on(name, handler)` для подписки и `emit(name, data)` для отправки события. Подписки хранятся в `Map`.
- `model.js` — `connectModel(bus)`: подписывается на `rank:requested`, меняет массив и публикует `squad:changed`.
- `view.js` — DOM-функции.
- `main.js` — подключает подписчика таблицы и публикует `rank:requested` после нажатия кнопки.

## Маршрут изменения звания

```text
View → bus.emit("rank:requested", {index, rank})
                 ↓
Model: обработчик "rank:requested"
                 ↓
Model: bus.emit("squad:changed", squad)
                 ↓
View: подписчик "squad:changed"
                 ↓
render(squad)
```

View не вызывает `model.changeRank()` напрямую, а Model не вызывает `view.render()`. Оба знают только названия событий, по которым договорились взаимодействовать.

## Небольшой эксперимент

В `main.js` измените имя публикуемого события `rank:requested`. Модель перестанет получать уведомление, поскольку подписана на прежнее имя. Верните его и снова попробуйте изменить звание.

## Чем отличается

От **Flux** — отсутствием единственного обязательного маршрута `Action → Reducer → Store`: произвольные подписчики могут реагировать на разные сообщения. В отличие от распределённых брокеров сообщений, наша шина работает синхронно в одной вкладке браузера и не сохраняет события.

## Как запустить

Откройте корень репозитория в VS Code и запустите **Live Server**. Перейдите к странице `architecture-patterns/events/index.html`. Используется `<script type="module" src="main.js">`, поэтому прямое открытие через `file://` не рекомендуется.

В интерфейсе выберите бойца, задайте другое звание и нажмите **«Изменить звание»**. Сравните изменённую строку таблицы с журналом «Трассировка: кто вызвал кого?». При обновлении страницы данные возвращаются к исходным: в примере они изменяются только в памяти браузера, без записи на диск.

`index.html` задаёт элементы интерфейса, `style.css` отвечает за оформление, `data.js` содержит одинаковые для всех девяти примеров сведения об 11 вымышленных бойцах. Это общая учебная основа; архитектурные различия находятся в остальных файлах.
